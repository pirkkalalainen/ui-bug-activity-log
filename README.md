# Relay — Deploy Log

Tiny static demo app: a deploy log viewer, 5,000 log lines spanning the last two weeks
of deploys, virtualized so only the visible rows are ever in the DOM (do not "fix"
anything below by rendering every row). Sticky date dividers group entries by day.

Open `index.html` in a browser.

## User feedback

A few people on the team have said the log viewer "feels a bit off" lately — nothing
specific, no repro steps, just a general sense that something's not quite right. Please
look into it and fix whatever you find.
